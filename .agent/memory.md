# Agent Memory

- The default branch and canonical source branch is `development`.
- `Portfolio-Vite` is the active public application.
- `Portfolio-Vite/Pages` owns the existing Arcade route structure and game
  folders.
- `Portfolio-Vite/cli` owns deterministic portfolio and Arcade tooling.
- `ChatHub-Harness` owns prompt-gated workflow source.
- `ChatHub-Output` is generated review output, not source input.
- `legacy/old-root-site` is historical and must not silently become active.
- Generated builds, runs, browser profiles, credentials, and downloaded
  dependencies do not belong in commits.
