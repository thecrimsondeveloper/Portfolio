# Workflow

Status: active

1. Select one application, Arcade, tooling, ChatHub, or documentation surface.
2. Read its owning files and documented boundaries.
3. Record the intended user-visible or operational outcome.
4. Make the smallest coherent change within that ownership boundary.
5. Run the matching build, focused command, and browser validation.
6. Record limitations and evidence without committing generated local state.
7. Integrate through a review branch into the actual default branch.
