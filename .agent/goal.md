# Goal

Status: active

Keep the portfolio accurate, buildable, navigable, and safe to publish while
making each project surface understandable to human maintainers and bounded
agents.

## Success Criteria

- `Portfolio-Vite` remains the canonical application and builds successfully.
- Existing Arcade routes remain stable and playable.
- Tooling and generated output remain isolated from application source.
- Public documentation distinguishes implemented behavior from generated or
  historical material.
- Changes carry focused validation and sanitized evidence.
