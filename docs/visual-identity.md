# Visual Identity

![Crimson Wheeler portfolio social card](assets/brand/social-card.png)

The repository image pack presents the portfolio as one connected route through
systems architecture, dependable delivery automation, spatial and gameplay
experiments, and the browser Arcade. The central star and harbor reference the
canonical site's Star Harbor framing.

## Visual Language

- Charcoal reflects the canonical application's dark operational shell.
- Coral matches the default portfolio accent and marks forward movement.
- Teal connects technical systems, routes, and the harbor environment.
- Warm ivory keeps diagrams and project groups readable.
- Restrained cyan supports interaction and spatial-system details.

## Asset Pack

Reusable files live under `docs/assets/brand/`:

- `logo-transparent.png`: guiding star inside a modular systems frame.
- `logo-mask.svg`: editable single-color mark.
- `cover-1280x640.png`: connected portfolio-domain cover.
- `social-card.png`: cover with the repository mark.
- `manifest.json`: hashes, processing settings, dimensions, and validation.

Keep the architecture blocks, delivery route, spatial scene, Arcade screens,
harbor, and mark fully visible. The artwork summarizes repository scope; it is
not a screenshot of the live site.
