## Prompt

Build a small self-contained browser arcade game called Neon Relic Sprint.

The player controls a luminous relic runner in a dark neon ruin. They collect relic sparks, dodge roaming glitch sentries, and use a short pulse dash to escape danger. The game should be playable directly from GitHub Pages after the run.

Use no external assets. Make the output one complete browser game with clear win/lose text, score, timer, keyboard controls, and replay.
