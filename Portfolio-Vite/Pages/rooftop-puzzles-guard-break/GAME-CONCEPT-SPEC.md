# Game Concept Spec

## Identity

- Title: Rooftop Puzzles: Guard Break
- Description: Navigate rooftop and tree spaces with sprint and crash, survive warden-led pressure, and turn each run into unify progress.
- Objective: Use sprint and crash to survive warden patrols, secure relic routes, and turn each run into unify, evolve progress.
- Distinctiveness: Feel like a fast improviser navigating rooftop hazards while turning sentry pressure into opportunities.

## Seed Summary

Generated game seed combination:
- Themes: noir investigation
- Environments: rooftop maintenance rails
- Settings: midsummer heat
- Character motivations: unmask a hidden group
- Movement mechanics: grapple and zipline, slide and vault
- Core loops: solve motion puzzles to advance
- Progression loops: restore environmental systems
- Completion loops: tower climb to trigger signal
- Rewards: artifact sets, collectibles
- Antagonists: patrolling automatons
- Visual styles: warm neon
- Audio styles: field recording textures
- Interaction patterns: hold-and-release momentum
- Production focus: build a single page interactive proof
