
    # ACTION EXTRACTION

    1. Action Map

   1. Infiltration: Players navigate the underground cavern, avoiding detection and solving motion puzzles to progress.
   2. Cargo Balancing: Players balance cargo on their character to traverse obstacles and reach new areas.
   3. Grapple and Zipline: Players use grapple points and ziplines to move between different levels and reach secret areas.
   4. Motion Puzzles: Players solve puzzles that involve manipulating the environment and using movement upgrades.
   5. Ceremony Completion: Players participate in a ceremony to complete the game and unlock rewards.
   6. Secret Area Access: Players explore the cavern to find hidden areas and collect artifact sets.

2. Detail Items

   1. Hidden Society: Create a rich, immersive society with unique characteristics, rules, and roles.
   2. Underground Cavern: Design a visually engaging and varied cavern environment with multiple levels and interconnected areas.
   3. Festival Night: Implement a festival night setting with atmospheric lighting, decorations, and music.
   4. Movement Upgrades: Design movement upgrades that enhance players' abilities and unlock new paths.
   5. Unstable Machinery: Create antagonistic machinery that challenges players and adds tension to the gameplay.
   6. Cinematic Noir Lighting: Implement a cinematic noir lighting style that enhances the mood and atmosphere.

3. Task Summary

   1. Implement Component-Entity-System (CES) Architecture.
   2. Design data-driven components, entities, and systems for game objects and mechanics.
   3. Create a scene management system for loading, unloading, and transitioning between levels.
   4. Develop a clear gameplay loop with input, update, and rendering logic.
   5. Implement AI and pathfinding systems using behavior trees, navigation meshes, and flocking algorithms.
   6. Design and implement cinematic noir lighting and sparse piano audio.
   7. Implement point-and-click traversal and interaction patterns.
   8. Create a prototype with the six identified game activities and detail items.
