Design of Data-Driven Three.js + Rapier Game

Objectives
-------

The main objective of this game is to create a three.js + Rapier-based experience that showcases the power of data-driven design. The game will use real-world data to generate a unique and engaging experience for the player, with the goal of educating them about the importance of data in our daily lives.

Loop Structure
-------

The game will have a simple loop structure, consisting of the following steps:

1. The player is presented with a set of data, such as a dataset of climate change statistics.
2. The player can interact with the data, using tools provided by the game to explore and analyze it.
3. Based on the player's interactions, the game generates a three.js + Rapier-based environment that reflects the data. For example, if the data shows a rise in global temperatures, the game might generate a world that is gradually becoming hotter and more inhospitable.
4. The player can then explore this environment, using the physics engine provided by Rapier to interact with it in a realistic way.
5. The player's actions and interactions within the environment will generate new data, which can be used to further modify and expand the game world.
6. The game continues in this way, with the player constantly exploring, analyzing, and interacting with the data to generate new and unique experiences.

Visual Style
-------

The visual style of the game will be clean and minimalist, with a focus on showcasing the data and the three.js + Rapier-based environment. The game will use a muted color palette, with bold, eye-catching graphics used to highlight important data points and interactions.

The game will also make use of animation and motion graphics to bring the data to life and make it more engaging for the player. For example, if the data shows a trend over time, the game might use animation to show this trend unfolding before the player's eyes.

Game Delivery
-------

The game will be delivered as a web-based experience, using the three.js and Rapier libraries to provide the necessary 3D graphics and physics capabilities. The game will be optimized for a wide range of devices, including desktop computers, laptops, and mobile devices.
