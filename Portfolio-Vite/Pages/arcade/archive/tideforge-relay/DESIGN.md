Design of Data-Driven Three.js + Rapier Game

Objectives
---------

The main objective of this game is to create a three.js + Rapier physics-based experience that is driven by data. The game will feature a variety of interactive objects and environments that are controlled by real-world data feeds. The player will be able to explore and manipulate these objects and environments in real-time, creating a unique and dynamic gameplay experience.

Loop Structure
---------------

The game will have a simple loop structure, with the player able to explore and interact with the various data-driven objects and environments. The player will be able to use their keyboard and mouse to move around and manipulate the objects, with the game updating in real-time based on the latest data feeds. The player will also be able to customize the data sources and parameters that drive the game, allowing for a wide range of possible experiences.

Visual Style
-------------

The game will have a minimalist, abstract visual style, with a focus on clean lines and simple shapes. The objects and environments will be made up of basic geometric forms, such as cubes, spheres, and cylinders, with a limited color palette. This will help to keep the focus on the data-driven aspects of the game, and allow the player to easily understand and manipulate the objects and environments.

Game Delivery
--------------

The game will be delivered as a web-based experience, using the three.js and Rapier libraries to create the physics-based gameplay. The data feeds will be integrated into the game using web APIs, allowing for real-time updates and interactions. The game will be accessible from any modern web browser, and will be optimized for both desktop and mobile devices.
